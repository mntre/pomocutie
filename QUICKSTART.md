# ⚡ Quick Start Guide

Get your Pomodoro Timer running in 3 minutes!

## 🏃 For Local Development

```bash
# 1. Navigate to the project
cd c:/Users/charvin.penaverde/Desktop/pomodoro

# 2. Install dependencies (if not already done)
npm install

# 3. Start the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser!

## 🌐 For Vercel Deployment

### Quick Deploy (2 minutes)

1. **Push to GitHub:**
   ```bash
   # Create a new repo on GitHub, then:
   git remote add origin YOUR_GITHUB_URL
   git push -u origin main
   ```

2. **Deploy on Vercel:**
   - Go to [vercel.com/new](https://vercel.com/new)
   - Click "Import" next to your repository
   - Click "Deploy"
   - Done! 🎉

Your app is now live at `https://your-project.vercel.app`

## 📱 Using the App

### Start Studying

1. **Select your task** from the dropdown (e.g., "Financial Accounting")
2. **Click "▶️ Start"** to begin your 25-minute Pomodoro
3. **Stay focused** while Bubu studies with you 🐻

### Take Breaks

4. When the timer completes, you'll get a notification
5. **Short breaks** (5 min) after each Pomodoro
6. **Long breaks** (15 min) after every 4 Pomodoros
7. Dudu will keep you company during breaks 🐼

### Track Progress

- See your **completed Pomodoros** counter
- Check your **statistics** for total study time
- Build your **streak** by studying consistently

### Customize

- Toggle **dark mode** with the sun/moon button
- Get **new quotes** for motivation
- **Reset stats** if you want to start fresh

## 🎯 Pomodoro Technique Tips

1. **Choose a task** before starting
2. **Eliminate distractions** during work sessions
3. **Take breaks seriously** - rest is important!
4. **Track your progress** - celebrate completed Pomodoros
5. **Adjust if needed** - the technique should work for you

## 🐛 Quick Fixes

### App won't start?
```bash
# Delete node_modules and reinstall
rm -rf node_modules
npm install
npm run dev
```

### Build failing?
```bash
# Check for TypeScript errors
npm run build
```

### Notifications not showing?
- Click "Allow" when prompted for permissions
- Check browser notification settings
